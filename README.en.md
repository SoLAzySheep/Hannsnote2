# Screen Tuner 1.10.0

| [简体中文](README.zh-CN.md) | **English** |
|:---:|:---:|

Screen Tuner is an Android display color adjustment app designed primarily for the HannsNote2 RK3566. This software was developed entirely with AI. More resources are available on the [Keji Wanjia](https://www.kejiwanjia.net/) website.

## Features

- Adjust brightness, contrast, saturation, and hue.
- Adjust gamma and the red, green, and blue channels.
- Use the floating panel to preview and tune the display while viewing other apps.
- Apply the recommended color preset from the main screen.

## Requirements

- Root access is required. Allow superuser access for `com.hannsnote.screentuner` in your root manager.
- Allow the app to display over other apps to use the floating panel.
- Designed for HannsNote2 RK3566. Other devices and firmware versions are untested.

## Safety Notice

This app uses privileged display controls. Root access and display tuning can affect device behavior. Use it at your own risk. The app is provided for learning and personal use, without warranty.
