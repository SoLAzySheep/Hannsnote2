# 屏幕校色 1.10.0

| **简体中文** | [English](README.en.md) |
|:---:|:---:|

屏幕校色是一款 Android 屏幕色彩调节软件，主要面向 HannsNote2 RK3566。本软件完全由 AI 开发，更多资源详见[科技玩家](https://www.kejiwanjia.net/)网站。

## 功能

- 调节亮度、对比度、饱和度和色相。
- 调节伽马以及红、绿、蓝通道。
- 使用悬浮窗在浏览其他应用时预览并调整屏幕效果。
- 在主界面点击爱心，应用推荐调色方案。

## 使用要求

- 需要 Root 权限。请在 Root 管理器中允许 `com.hannsnote.screentuner` 获取超级用户权限。
- 使用悬浮窗需要授予“显示在其他应用上层”权限。
- 主要适配 HannsNote2 RK3566；其他设备和固件版本未经测试。

## 风险提示

本软件会通过 Root 权限调用显示控制接口。Root 操作和屏幕调节可能影响设备运行，请自行评估并承担风险。本软件仅供学习和个人使用，不提供任何担保。
